# 体验评测方法论

本文档不进入初始上下文（load: on_demand）。模型需要判断评级或撰写口径说明时，
用 read_reference 工具读取。

## 一、指标口径

### NPS
0–10 分量表，问题固定为「你有多大可能把它推荐给同事或朋友」。
- 推荐者（Promoter）：9–10 分
- 中立者（Passive）：7–8 分
- 贬损者（Detractor）：0–6 分

NPS =（推荐者数 − 贬损者数）/ 有效样本数 × 100

超出 0–10 的取值视为无效，剔除后再计算，不做截断。

### CSAT
5 分量表。默认 4 分及以上计为满意，阈值可在确认卡片中调整。
CSAT = 满意样本数 / 有效样本数

### 任务完成率
以用户自述为准（问卷中的「是否完成了本次任务」）。
不与埋点数据交叉校验 —— 若需交叉校验，属于另一个 skill 的范围。

## 二、评级标准

| NPS 区间 | 评级 | 说明 |
|---|---|---|
| ≥ 50 | 优秀 | 口碑驱动增长 |
| 20 – 49 | 良好 | 有正向口碑，仍有明显改进空间 |
| 0 – 19 | 一般 | 推荐者与贬损者基本抵消 |
| < 0 | 需改进 | 贬损者多于推荐者，需优先处理 |

## 三、样本量要求

- 总体结论：有效样本 ≥ 30
- 分组结论：单组有效样本 ≥ 确认卡片中设定的下限，低于则不单独出结论，
  只并入总体。这条是硬性的 —— 小样本分组的百分比波动极大，
  给出来会误导决策。

## 四、不做的事

- 不对缺失值做插补。缺就是缺，报告里写明「该项数据缺失」。
- 不做趋势外推。单次评测没有时间序列，任何「预计将提升 X%」都是编的。
- 不在样本量不足时给分组结论。
